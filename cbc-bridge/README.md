# CBC Local Bridge

جسر اختياري مكتوب بـPython القياسي يستقبل HL7 من جهاز CBC عبر TCP، يحلل رسائل `ORU^R01` ذات تأطير MLLP أو وضع HL7 خام محدد، ويحفظ عينات مرحلية في SQLite. لا يُنشئ نتيجة مختبر ولا يعتمدها. لم يُختبر على جهاز analyzer فعلي بعد؛ يجب ضبط الرموز والتأطير بعد استلام رسالة حقيقية من طراز الجهاز.

## متطلبات السلامة

- لا تفتح منفذ CBC (`5006` افتراضيًا) على الإنترنت أو في Port Forwarding. اسمح في جدار الحماية باتصال LAN من IP الجهاز فقط.
- اجعل `computerIp` عنوان واجهة حاسوب المعمل الفعلية (افتراضي المواصفة `192.168.1.111`) و`deviceIp` عنوان الجهاز (افتراضي `192.168.1.100`). إذا لم يكن العنوان موجودًا على الحاسوب فلن يبدأ الخادم.
- صورة الإعداد المرفقة تعرض: Local IP `192.168.1.100`، Server IP `192.168.1.111`، Mask `255.255.255.0`، Gateway `192.168.1.1`، Port `5006`، و`Trans Select=Net` و`Auto Trans=On` و`Trans Protocol=HL7`. هذه المعلومات تطابق إعداد الشبكة المقصود، لكنها لا تثبت إن كان HL7 مؤطرًا بـMLLP أو مرسلًا خامًا؛ ابدأ بـMLLP القابل للضبط ولا تعتمد `raw-idle` إلا بعد فحص رسالة فعلية.
- التكامل متوقف افتراضيًا. فعّله مدير النظام فقط بعد ضبط الاتصال وإنشاء رمز الجسر. لا يكشف التطبيق قيمة الرمز مجددًا بعد مغادرة الإعدادات؛ يخزن SHA-256 فقط.
- احتفظ بـ`CBC_BRIDGE_TOKEN` في متغير بيئة أو ملف `.env` محلي محمي خارج Git. لا تسجل رسائل HL7 كاملة أو أسماء المرضى في سجلات الخدمة.
- في Hosted Mode، الجسر (حاسوب المعمل) هو الذي يبدأ HTTPS صادرًا إلى الموقع. لا تجعل الخادم المستضاف يتصل بـIP جهاز LAN. يجب أن يبدأ `CBC_SERVER_URL` بـ`https://` في هذا الوضع.

## التشغيل اليدوي

من مجلد `cbc-bridge`، اضبط `CBC_SERVER_URL` (قاعدة عنوان API، دون مسار) و`CBC_BRIDGE_TOKEN` المولد من إعدادات المدير، ثم شغّل:

```sh
python3 bridge.py
```

مثال ملف بيئة محلي غير متعقب:

```dotenv
CBC_SERVER_URL=http://127.0.0.1:3000
CBC_BRIDGE_TOKEN=PASTE_GENERATED_SECRET_HERE
CBC_SQLITE_PATH=/var/lib/cbc-bridge/cbc-bridge.sqlite3
CBC_MAX_MESSAGE_BYTES=1048576
```

في Windows PowerShell:

```powershell
$env:CBC_SERVER_URL = "https://clinic.example.org"
$env:CBC_BRIDGE_TOKEN = "PASTE_GENERATED_SECRET_HERE"
py .\bridge.py
```

تقرأ الخدمة إعدادات IP والمنفذ والبروتوكول من إعدادات المدير عبر API موثق. خزّنت الرسائل في outbox محلي، وتُعاد محاولة رفعها بعد انقطاع الشبكة. إعادة المحاولة وإزالة التكرار لا تضمن فهم أي صيغة خاصة بالجهاز دون عينة حقيقية.

## التشغيل التلقائي

على Linux، انسخ ملف `cbc-bridge.service.example` إلى `/etc/systemd/system/cbc-bridge.service`، وعدّل `User` و`WorkingDirectory` و`EnvironmentFile` ومكان قاعدة SQLite، ثم:

```sh
sudo systemctl daemon-reload
sudo systemctl enable --now cbc-bridge
sudo systemctl status cbc-bridge
```

على Windows، شغّل `install_windows_task.ps1` كمسؤول بعد وضع ملف `cbc-bridge.env` خارج مجلد المستودع؛ ينشئ مهمة مجدولة عند بدء النظام تعمل بحساب SYSTEM. راجع السجل من Event Viewer/مخرجات المهمة، ولا تنسَ قاعدة جدار الحماية المقيدة بعنوان الجهاز.

## بروتوكول البيانات والحدود

- MLLP هو الافتراضي (VT, الرسالة، FS, CR). وضع `raw-idle` يستخدم مهلة سكون TCP ويجب اعتماده فقط إذا كانت طريقة إنهاء رسالة الجهاز مؤكدة.
- يحلل الجسر `MSH`, `PID-3`, `OBR-2/3/7`, و`OBX-3/5/6/7/8/14` من دون الاعتماد على ترتيب OBX. يستخدم أول معرف من `PID-3` ويرفض الرسائل التي تفتقد PID-3 أو معرف عينة OBR أو نتائج OBX.
- لا تحفظ قاعدة التطبيق رسالة HL7 الخام؛ تحفظ معرف المريض/العينة، رمز الرسالة، زمن الاستلام، ونتائج OBX مع القيم والوحدات والمدى والراية الأصلية. تحفظ SQLite محليًا صف outbox منفصلًا.
- لا تحويل للوحدات ولا افتراض رموز LOINC/خاصة بالشركة. الملف `client/src/lib/cbc-import.ts` يحتوي أسماء رموز عامة معلنة؛ عدّل mapping فقط بعد مراجعة ملف HL7 فعلي من الطراز.
- فحص هوية المريض في الواجهة تطابق حرفي بين PID-3 الأول ورقم ملف المريض المحدد. عدم التطابق يمنع النقل، ولا تُنشأ سجلات مرضى من الجهاز.
- يحفظ الفني يدويًا أو يطبع كما في المسار الحالي. عند الاستيراد لا يُعتمد أو يحفظ التقرير النهائي تلقائيًا؛ تبقى النتيجة مسودة بالواجهة حتى يضغط الفني زر الحفظ الموجود.

## الاختبار المحلي

```sh
python3 -m unittest discover -s . -p 'test_*.py' -v
```

هذه الاختبارات تثبت سلوك parser/MLLP وتكرار المحتوى فقط. اكتمال التكامل التشغيلي يتطلب: إعداد شبكة الجهاز، رسالة HL7/MLLP حقيقية، تأكيد separators/OBR/OBX/code mapping، واختبار استيراد آمن إلى مريض معروف. لا تُعلن Connected على جهاز حقيقي قبل تلك التجربة.
